📖 Project Overview

Peer‑Tutor‑Club is a full‑stack web platform built for student‑led peer tutoring. Designed for the Agora Business Union’s peer‑learning community, this system enables decentralized tutoring scheduling, knowledge‑resource sharing, structured quiz practice, and collaborative student discussion. Communities can be separated by country, city, and individual school to keep local student groups independently managed.

Instead of rigid pre‑arranged tutoring pairs, our workflow is request‑driven: students submit tutoring requests with their needs, and other members can sign‑up for open sessions through a live public calendar. Beyond one‑on‑one tutoring, the platform integrates self‑study tools, group workspaces, and built‑in utilities to form an all‑in‑one student learning hub.

✨ Core Features

🏫 Multi‑level Community Administration

• Partition communities by country → city → school for isolated group management

• Union‑member permission panel: different access rights for regular members & organization administrators

• Each school/community runs its own tutoring pool while sharing the global toolset

📅 Peer Tutoring Request & Scheduling System

• Students submit tutoring requests (Submit Request)

◦ Select from 11+ subjects, covering most AP courses & local school curricula

◦ Fill in preferred tutor, expected date‑time, personal notes & learning goals

• Real‑time interactive calendar visualizes all open tutoring sessions

• Other users browse the calendar, view session details, and send join requests for available tutoring slots

• Dynamic status updates for pending / ongoing / finished tutoring events

📚 Learning Resource Repository

• Members upload and share personal notes, review sheets, homework solutions and study materials

• Centralized resource library for each community for quick access to student‑generated content

📝 Quiz & Practice Module (College‑Board‑Aligned)

• Administrators create practice sets & quizzes following College‑Board question patterns

• Questions tagged by knowledge points and difficulty levels

• Two quiz modes: full random practice, or targeted practice on selected knowledge topics

• Built‑in error notebook / mistake log: save wrong answers for later review

💬 Collaboration & AI Assistant

• Create & join study groups for topic‑focused group discussions

• Built‑in AI helper for instant learning support inside group workspaces

• Simple social feed (optional): members may post study‑related thoughts and updates

🛠️ Built‑in Handy Utilities

• Text translator

• Standard calculator

• 2D graphing calculator

• 3D graphing calculator

🧑‍💻 Target Users

• High‑school students seeking peer‑to‑peer academic support

• Student‑run clubs / unions that organize peer‑tutoring programs

• Administrators managing cross‑school student learning communities
